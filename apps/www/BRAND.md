# Entwine logo

`logo.png` is the transparent raster brand mark used by the website and favicon.
It was generated with the built-in image generation tool for this project.

Prompt: Create a single polished logo symbol for Entwine, an open-source project
connecting repository Markdown documentation into a knowledge graph. Two
interwoven geometric strands form a compact lowercase e-like knot with clear
negative space and elegant rounded corners. Flat monochrome charcoal #171717,
neutral and restrained. Transparent background, centered square composition,
symbol fills 85% of canvas. No text, wordmark, gradients, shadows, mockup, or
extra icons. Legible at favicon scale.
