# Security

Entwine 0.1.x is experimental. Use the newest available patch release. The compiler
never executes Markdown code or frontmatter, and never fetches external links.
Raw Markdown HTML is escaped. Documentation symlinks and escaping paths are refused.

Treat copied static assets as author-controlled content. Run the dev server only
locally; it binds to loopback and is not intended as a production server.

For a vulnerability, use GitHub's private vulnerability reporting on the upstream
repository when available, or contact its maintainer privately through their
profile. Include affected version, reproduction steps, and impact. Do not post
exploit details publicly before a fix can be evaluated. No response-time guarantee
is offered by this early volunteer project.
