# Roadmap

This page describes future intent. The [current state](state.md) lists what works.

## Next milestone

Gather feedback from real repositories, improve graph readability for dense
documentation, and strengthen cross-platform path tests. Define a release and
binary distribution workflow before promising package-manager installation.

## Later considerations

Consider small opt-in configuration only when real users demonstrate a need.
Evaluate search and context schema evolution separately. Preserve the
[canonical model boundary](architecture.md#canonical-representation).

No integration or AI roadmap is promised for this release.
